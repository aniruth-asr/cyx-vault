# Resources

This directory is for reusable knowledge extracted from CTFs and security research.

Suggested organization:

```text
resources/
├── techniques/
│   ├── web/
│   ├── crypto/
│   ├── pwn/
│   ├── reverse/
│   ├── forensics/
│   └── hardware/
├── cheatsheets/
├── tools/
└── references/
```

A technique note should focus on the reusable concept rather than a single flag. Link back to example challenges when useful.
