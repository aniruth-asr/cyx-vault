# Curated Challenges

This area is for interesting challenges, techniques, and external writeups worth studying even when they were not originally solved by this repository's contributors.

Use a category-first layout:

```text
curated/<category>/<challenge>/
```

Each entry should clearly include:

- original CTF / event
- challenge author, if known
- original source URL
- original writeup URL, if one was used
- why the challenge is interesting
- your own notes, reproduction, or alternative analysis

Do not mirror someone else's article without permission. Link to the original and add value through your own explanation or reproduction.
